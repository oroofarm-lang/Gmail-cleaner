# Sticker Bomb — accepted direction, 2026-10-06

Replaces previous paper/lime/pop accents. App working screens stay white and legible; selected hero, report and footer areas use a single original SVG image collage. Original reference is a visual guide only; no third-party garment artwork is copied.

Tokens: --collage-bg grayscale only; --blood-red #D92B2B; --label-bg #000; --label-fg #fff; --eye-badge-border jagged 6px red; --text-stroke-price 3px white. Accent red is rare and reserved for brand accents/eye sticker. Monochrome collage is an external background image, not dozens of DOM decorations. The image has one central white eye with a brand-red ink/drip element. Dense envelope, eye, mouth, star, stamp and shield drawings overlap and bleed at edges.

Text labels: black/white, square corners, bold uppercase typography; essential long text stays level. Oversized graphic wordmark bleeds only as decorative image/text, not as the accessible heading. Key title, count and actions must remain inside viewport at 320px. No information relies on color or decoration. Motion respects reduced-motion.
