# Processor inventory — draft

| Provider                       | Role / potential data                                                | Status / required verification                                                                                         |
| ------------------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Sites / OpenAI hosting gateway | Authenticated identity and deployed UI/runtime                       | Connected platform; owner must establish contractual entity, regions, subprocessors, retention and DPA                 |
| Cloudflare Workers / D1        | Application code, relational mail metadata and encrypted credentials | Selected through host; actual account/region/backups/access must be recorded                                           |
| Google Gmail / OAuth           | Mailbox provider and authorization                                   | Live credentials/consent screen not configured; user directs authorized API processing                                 |
| OpenAI API                     | Optional bounded metadata for structured proposals                   | Integration adapter only; no app API credential verified, sharing requires informed consent and policy/contract review |
| Chrome local extension         | Locally stored dashboard URL                                         | No remote processor involved until user opens dashboard                                                                |

No analytics, advertising or monitoring processor is configured by these documents. Do not list a provider as approved solely because tools can call it. Record legal entity, agreement/DPA, processing region, subprocessors, access roles, data categories, retention and transfer safeguard for every activated provider. Inventory changes require policy update and any appropriate customer notice before new processing begins.
